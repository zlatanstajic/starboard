# Security Policy

## Supported Versions

Starboard does not publish versioned releases. Security fixes are made on the current `master` branch. Older commits and independently deployed copies are not maintained.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to [contact@zlatanstajic.com](mailto:contact@zlatanstajic.com) with `Starboard security report` in the subject. Do not open a public issue or pull request for a vulnerability before coordinating disclosure with the maintainer.

Include the affected feature, steps to reproduce, the potential impact, and any relevant version or commit. Share only the information needed to investigate; do not send passwords, API tokens, or other sensitive data.

The maintainer will review the report, follow up as soon as practical, and coordinate a fix and public disclosure with you. Please allow time for investigation and remediation before publishing details.

For ordinary bugs and feature requests, use the repository's [GitHub issues](https://github.com/zlatanstajic/starboard/issues).
